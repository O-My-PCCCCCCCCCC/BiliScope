# BiliScope

读取并分析自己 B 站账号数据的本地工具：扫码登录 → 自动拉取观看历史、收藏、关注 → SQLite 存储 → Web 仪表盘可视化。

## 运行

```bash
pip install -r requirements.txt
python run.py
```

打开 http://localhost:8000 ，在「设置」页扫码登录 B 站账号，点「立即同步数据」。

## 功能（M1）

- 扫码登录（Cookie 存本地 config.json）
- 同步观看历史 / 收藏夹 / 关注列表
- 概览仪表盘：近 30 天观看趋势、常看 UP 主 TOP10、观看时段/分区分布
- 观看历史搜索与分页、收藏夹浏览

## 功能（M2 监测）

- 失效视频检测：自动检查历史/收藏中的失效视频，生成提醒
- UP 主更新提醒：检测关注 UP 主的最新投稿（WBI 签名接口）
- 定时任务：每天 03:00 同步、04:00 失效检测、每 6 小时 UP 主更新（APScheduler）
- 监测中心页：提醒列表 / 失效视频 / UP 主更新，未读角标

## 功能（M3 报告与配置）

- 观看数据周报/月报：观看量、常看 UP 主、分区分布
- SMTP 邮件通知：报告/提醒发到邮箱，设置页可配置并发送测试邮件
- 定时生成报告：每周日/每月 1 号自动生成

## 功能（M4 内容分析）

- 多 LLM 提供层：Claude / OpenAI 兼容（DeepSeek 等）/ Ollama 本地
- 视频内容标签 + 摘要，主题分布图表
- 硬件检测 + 本地模型自动推荐（设置页一键）

## 功能（M5a AI 助手）

- 通用聊天界面，多 LLM 提供层（Claude / OpenAI 兼容 / Ollama）
- **工具调用**：让 AI 操作收藏夹——新建/删除收藏夹、移动视频、自动整理
- 示例：「把音乐收藏夹里的视频整理到新文件夹」
- 需先在设置页配置 LLM（Ollama 本地免费 / DeepSeek / Claude）

## 测试

```bash
python -m pytest tests/ -v
```

> 测试全部使用 mock 数据，不会真实请求 B 站。
